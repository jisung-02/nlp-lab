# 경희대학교 자연어처리 연구실

**Kyung Hee University · Natural Language Processing Lab**

[연구실 홈페이지](https://nlp.khu.ac.kr/) · [English](https://nlp.khu.ac.kr/?lang=en)

경희대학교 자연어처리 연구실은 언어 이해, 질의응답, 대화, 정보검색, 텍스트 마이닝을 연구합니다. 이 저장소는 연구실의 연구 활동과 구성원, 연구성과, 소식을 소개하는 웹사이트의 소스 코드를 관리합니다.

## 주요 기능

- **연구실 소개와 소식** — 연구실 소개, 최근 소식, 메인 이미지 슬라이드
- **연구 분야와 성과** — 프로젝트 목록·상세, 관련 논문, 연도별 논문 조회
- **구성원과 연락처** — 구성원 소개, 연구실 위치와 지도
- **한국어·영어 지원** — 언어별 콘텐츠와 페이지 탐색
- **관리자 화면** — 구성원·프로젝트·논문·소식 편집과 이미지 관리

## 구성과 운영

FastAPI와 Jinja2로 페이지를 렌더링하고, SQLModel과 SQLite로 콘텐츠를 저장합니다. 데이터베이스 변경 이력은 Alembic으로 관리합니다.

웹 개발 지식이 없어도 일상적인 유지보수를 할 수 있도록 구성을 최소화하고 운영 명령을 통합했습니다. 콘텐츠는 관리자 화면에서 편집하고, 실행·업데이트·복구는 정해진 명령으로 처리합니다. 자세한 절차는 아래 문서에서 확인할 수 있습니다.
